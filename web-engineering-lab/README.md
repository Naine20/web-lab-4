# Web Engineering Lab 04

This is a clean Lab 04 starter/completed version for a student who did not complete Labs 2 and 3.

## Files

- `public/index.html`
- `public/styles.css`
- `public/script.js`
- `public/main.js`
- `public/utils.js`
- `NOTES.md`

## Run in VS Code

1. Open this folder in VS Code.
2. Install the Live Server extension if needed.
3. Open `public/index.html`.
4. Click **Go Live** in the bottom-right corner.
5. Test the page in Chrome.
6. Open DevTools with `F12`.

Do not run the page only by double-clicking `index.html`, because ES modules should be served through Live Server.
